# 보안 조치 필요

모델 데이터 감사 중
`연면적추출/senior-facility-area-mvp/data/output/smoke_results.csv`의 저장된 오류
URL에 API `serviceKey`가 평문으로 포함된 정황을 확인했습니다. 같은 값이 현재
체크아웃의 조상 Git 이력에도 남아 있으므로 파일만 지우는 것으로는 해결되지
않습니다.

키 값은 모델 코드·입력·아티팩트에 사용하거나 복사하지 않았습니다.

권장 순서:

1. 발급기관에서 기존 키를 즉시 폐기하고 새 키를 발급합니다.
2. 새 키는 환경변수 또는 비밀 저장소로만 주입하고 CSV·로그·오류 URL에는
   기록하지 않습니다.
3. 공유 저장소라면 `git-filter-repo` 또는 BFG로 과거 blob을 제거한 후 관련
   협업자와 force-push 절차를 조율합니다.
4. 새 키 회전이 끝난 뒤에만 이력 정리를 수행합니다. 이미 노출된 기존 키는
   이력 삭제만으로 다시 안전해지지 않습니다.
